# 📊 วิธีเชื่อมต่อ Google Sheets เป็น Database (เสร็จใน 1 นาที)

คู่มือนี้จะแนะนำการนำโค้ด `Code.gs` ไปติดตั้งใน Google Sheets ส่วนตัวของคุณ เพื่อให้แอป To-Do List สามารถบันทึกและซิงค์ข้อมูลแบบเรียลไทม์ได้ตลอด 24 ชั่วโมง โดยไม่มีค่าใช้จ่าย!

---

### ขั้นตอนที่ 1: สร้าง Google Sheets ใหม่
1. เปิดเบราว์เซอร์ไปที่ [https://sheets.new](https://sheets.new)
2. ตั้งชื่อไฟล์ Spreadsheet ตามต้องการ เช่น `My Tasks Database`

---

### ขั้นตอนที่ 2: วางโค้ด Apps Script
1. ที่เมนูด้านบนของ Google Sheets คลิก **"ส่วนขยาย" (Extensions)** -> เลือก **"Apps Script"**
2. ลบโค้ดเริ่มต้นในไฟล์ `Code.gs` ออกทั้งหมด
3. คัดลอกเนื้อหาทั้งหมดจากไฟล์ [`Code.gs`](./Code.gs) ในโฟลเดอร์นี้ แล้วนำไปวางแทนที่
4. กดปุ่มบันทึก 💾 (Save) ด้านบน

---

### ขั้นตอนที่ 3: Deploy เป็น Web App
1. คลิกปุ่มสีน้ำเงิน **"การทำให้ใช้งานได้" (Deploy)** ที่มุมขวาบน -> เลือก **"การทำให้ใช้งานได้ใหม่" (New deployment)**
2. คลิกไอคอนฟันเฟือง ⚙️ ข้าง "เลือกประเภท" -> เลือก **"เว็บแอป" (Web app)**
3. ตั้งค่าดังนี้:
   - **คำอธิบาย (Description):** `To-Do API`
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (Me)`
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)`  *(⚠️ สำคัญมาก ต้องเลือก Anyone เพื่อให้เว็บแอปสามารถส่งข้อมูลมาบันทึกได้)*
4. คลิก **"ทำให้ใช้งานได้" (Deploy)**
5. หากมีหน้าต่างขอสิทธิ์ ให้คลิก **"ให้สิทธิ์การเข้าถึง" (Authorize access)** -> เลือกบัญชี Google ของคุณ -> คลิก **"ขั้นสูง" (Advanced)** -> คลิก **"ไปที่... (ไม่ปลอดภัย) / Go to ... (unsafe)"** -> คลิก **"อนุญาต" (Allow)**
6. คัดลอก **URL ของเว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`

---

### ขั้นตอนที่ 4: นำ URL มาใส่ในแอป To-Do List
1. เปิดแอป To-Do List บนมือถือหรือเบราว์เซอร์
2. แตะที่ปุ่มรูป **📊 Google Sheets** ด้านบน
3. วาง Web App URL ที่คัดลอกมาลงในช่อง แล้วกด **"เชื่อมต่อและซิงค์ข้อมูล"**
4. ระบบจะทดสอบและสร้างหัวตารางใน Google Sheet ให้อัตโนมัติ พร้อมซิงค์รายการงานทั้งหมดทันที! 🎉
